# Gravitask

마감이 다가오는 걸 읽지 않고 **느끼게** 하는 Windows 바탕화면 할 일 위젯.

할 일은 마감을 향해 떨어집니다. 이름은 거기서 왔습니다.

기존 할 일 위젯은 두 극단으로 갈라져 있습니다. Rainmeter 계열은 예쁘지만 할 일
관리가 안 되고, Microsoft To Do 계열은 기능은 완전하지만 "3일 남음"을 글자로
알려줄 뿐 시각적 압력이 없습니다. 이 프로젝트는 그 사이를 노립니다.

## 핵심 아이디어 — 2구역 축

할 일은 범주별 세로축에 쌓이는데, 축이 **24시간 경계로 나뉩니다.**

```
  ┌─────────────────┐
  │  대기 구역       │   마감이 하루 이상 남은 일들.
  │  · 균등 간격     │   순서와 개수만 전달합니다.
  │  · 순서 기반     │
  ├ ─ ─ ─ ─ ─ 24H ─ ┤   ← 이 선을 넘는 순간이 곧 알림
  │  활주로          │   24시간 이내로 들어온 일들.
  │  · 실제 시간 눈금 │   마감선을 향해 연속적으로 하강합니다.
  └━━━━━━━━━ DUE ━━━┘
```

한 축에 6시간과 26일을 함께 그리면 가시성이 무너집니다. 먼 일정은 순서만 알면
되고 임박한 일정은 정밀한 시간이 필요하니, 정보의 성격에 맞춰 표현을 나눴습니다.
카드가 경계를 넘어 활주로로 떨어지고 위 스택이 내려앉는 순간이 이 위젯의 핵심
알림 수단입니다.

## 임박 효과

색만으로 급함을 표현하면 색각 이상 사용자에게 전달되지 않습니다. 남은 시간을
**0~1 긴급도 값 하나**로 계산하고 여러 채널이 함께 반응합니다.

| 채널 | 여유 | 긴급 |
| --- | --- | --- |
| 위치 | 대기 구역 상단 | 활주로 바닥 |
| 색 | 저채도 청록 | 고채도 적색 |
| 형태 | 둥근 모서리 | 모서리 축소, 좌측 스트라이프 굵어짐 |
| 타이포 | 상대 표기 "9일 남음" | 절대 시각 "23:59까지" |
| 모션 | 정지 | 6초 주기 호흡 |

야간에는 채도와 모션이 자동으로 억제됩니다. 밤에 빨간 게 깜빡이면 위젯을 끄게
되니까요.

## 개발

```bash
npm install
npm run dev        # http://localhost:5273
npm run check      # 타입 검사
npm run test:parse # 자연어 파서 명세
```

개발 화면 하단의 **시간 이동 슬라이더**로 시간을 앞으로 돌려, 카드가 경계를
넘어 떨어지는 동작을 확인할 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/lib/theme.json` | 색 램프·곡선·경계 시간·모션을 한 곳에 모은 테마 |
| `src/lib/urgency.ts` | 긴급도 단일 진실 공급원. 모든 시각 속성이 여기서 파생 |
| `src/lib/parseInput.ts` | 한국어 자연어 입력 파서 |
| `src/lib/types.ts` | `Task`와 `TaskSource` 경계 |
| `src/lib/components/Column.svelte` | 2구역 렌더러 |

`theme.json`은 사람이 읽고 고칠 수 있게 열어둔 파일입니다. 색·반경·폰트·모션
강도·경계 시간을 바꿔 테마를 만들 수 있습니다.

### 투명도 조절

배경화면이 어두운 편이라 더 투명해도 괜찮다면 `theme.json`의
`surface.background` 알파값을 낮추세요.

```json
"surface": { "background": "rgba(18,19,27,0.72)" }
```

기본값 `0.72`는 **순백 배경화면 위에서도** 본문 대비 6.65:1, 보조 텍스트
4.62:1을 확보하도록 잡은 값입니다(WCAG AA 기준 4.5:1). 낮출수록 배경이 비쳐
보이지만 밝은 배경화면에서 글자가 묻히기 시작합니다. `0.55` 아래로는 권하지
않습니다.

투명 창에서는 CSS `backdrop-filter`가 아무것도 흐리지 못한다는 점을 기억하세요
— 창 뒤 바탕화면은 페이지 바깥이라 흐릴 대상이 아닙니다. 실제 흐림은
`tauri.conf.json`의 `windowEffects`(Windows acrylic)가 처리하고, 글자 대비는
전적으로 이 스크림이 책임집니다.

## 현재 상태

프론트엔드 코어가 동작합니다. 자연어 입력, 2구역 배치, 긴급도 파생, 로컬 저장.

**아직 없는 것:** Tauri 껍데기(투명 창, always-on-bottom, 트레이, 자동 시작),
범주 편집 UI, 자동 업데이트.

## 배포

태그를 밀면 GitHub Actions가 Windows 인스톨러를 만들어 Releases에 **초안**으로
올립니다. 내용을 확인하고 직접 게시하는 흐름입니다.

```bash
npm version patch    # package.json과 tauri.conf.json의 버전을 맞춘 뒤
git tag v0.1.1
git push origin v0.1.1
```

업데이터는 릴리스에 함께 올라가는 `latest.json`을 봅니다. 서명 개인 키는
저장소에 두지 않고 GitHub Actions Secrets에만 있습니다.

| 시크릿 | 내용 |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | `gravitask.key` 파일 내용 전체 |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 키 생성 시 정한 비밀번호 |

**개인 키를 잃으면 업데이트 경로도 잃습니다.** 기존 사용자는 다른 키로 서명된
업데이트를 거부하므로 전원이 수동 재설치를 해야 합니다. 백업해 두세요.

릴리스 워크플로는 태그 푸시에서만 돕니다. 이 저장소는 공개라, `pull_request`로
트리거하면 포크에서 온 코드가 서명 키에 접근할 수 있습니다.

## 알려진 제약

- **바탕화면 유지 동작은 환경에 따라 다를 수 있습니다.** 위젯은 포커스가 없을
  때 '바탕화면 바로 위'로 자리를 되돌려 Win+D를 견디는데, 이 동작은 Windows 11
  한 대에서만 검증했습니다. 다른 셸 확장(Fences, 배경화면 엔진 등)과 z-order를
  두고 다툴 수 있습니다.
- **서명 인증서가 없어** 첫 실행에서 SmartScreen 경고가 뜹니다.

## 로드맵

- **v1** — 로컬 할 일만. 캘린더 연동 없음. 서명 없이 배포하고 업데이터 뼈대만 포함
- **v1.1** — 비공개 iCal(ICS) 주소로 캘린더 축 추가. `TaskSource` 구현체 하나를 더
  끼우는 형태라 UI 변경 없음
- **v1.2** — 바탕화면 아이콘 뒤 부착(WorkerW), 코드 서명

캘린더는 OAuth 대신 ICS로 갑니다. Google Calendar 스코프는 민감 스코프로 분류돼
검증 전까지 평생 100명 상한이 걸리는 반면, 비공개 iCal 주소는 심사가 없고
Apple·Outlook 캘린더까지 같은 코드로 지원됩니다.

## 기술 스택

Tauri 2 + Svelte 5 + TypeScript. Windows에서 Tauri는 WebView2(Chromium) 위에서
돌기 때문에 Electron과 렌더링이 같으면서, 배포 용량과 메모리는 크게 작습니다.
하루 종일 켜두는 위젯에서 이 차이가 결정적입니다.
